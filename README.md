# Linux Data Processing Pipeline

A Linux-based data processing pipeline for automating data organization, cleaning, analysis, and workflow management.

## Project Goals

- Organize raw datasets
- Clean data using Linux commands
- Automate tasks with Bash scripts
- Analyze data using Python
- Generate logs and reports
- Build a production-style workflow

## Tech Stack

- Linux (WSL)
- Git & GitHub
- Bash
- Python
